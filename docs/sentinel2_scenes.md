# Sentinel-2 scenes used for validation

Source: Sentinel-2 L2A Cloud-Optimized GeoTIFFs on AWS open data (no login), found via the Element84 Earth Search STAC API (`https://earth-search.aws.element84.com/v1`, collection `sentinel-2-l2a`).
For each 12-day NISAR window and basin, the scene with the lowest cloud cover on the needed tiles was chosen, preferring dates near the window's midpoint.
Files used per tile: `SCL.tif` (cloud mask), `B11.tif` (SWIR, 20 m) and `L2A_PVI.tif` (true-colour preview). Downloaded copies are kept in `../aral sea DATA/sentinel2/`.
